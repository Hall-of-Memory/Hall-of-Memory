# Task-Vertrag

`tasks/` ist die alleinige Aufgabenquelle für Hall of Memory.

Jede Aufgabe hat eine eigene Markdown-Datei mit mindestens:

- `status`: `planned`, `active`, `blocked_external`, `blocked_technical`, `done`, `cancelled`
- Ziel
- Abhängigkeiten
- Akzeptanzkriterien
- Arbeitsjournal / Evidenz

Neue Restprobleme oder Folgethemen werden hier dedupliziert ergänzt. Kein paralleles Taskregister in Bureau oder einem anderen Repository.
